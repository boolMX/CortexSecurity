## 🚀 Descripción

**Cortex Security Suite** es una herramienta de ciberseguridad todo-en-uno diseñada para profesionales y entusiastas de la seguridad informática. Con una interfaz moderna y minimalista, ofrece funcionalidades completas desde el análisis de contraseñas hasta la detección de amenazas en tiempo real con integración en la nube.

> *"Potencia tu seguridad con inteligencia cloud y herramientas tácticas de nivel profesional."*

---

## ✨ Características Principales

| Módulo | Descripción |
|--------|-------------|
| 🔐 **Analizador de Contraseñas** | Calcula entropía, nivel de seguridad y verifica filtraciones en la red (Pwned Passwords). |
| 🧬 **Generador de Contraseñas** | Crea claves seguras y personalizables con longitudes de hasta 32 caracteres. |
| 🔑 **Hashes Criptográficos** | Genera firmas MD5, SHA-1 y SHA-256 en tiempo real. |
| 🎣 **Detección de Phishing** | Escanea URLs sospechosas y consulta blacklists en la nube. |
| 🧐 **Forense de Archivos** | Analiza integridad de archivos con SHA-256 y genera trazas forenses. |
| 🌐 **Escáner de Puertos** | Detecta puertos abiertos en IPs o dominios con reportes en la nube. |
| 🧩 **Reconocimiento de Subdominios** | Mapea subdominios de un objetivo y guarda los resultados. |
| 📦 **Bóveda Local Cifrada** | Almacena contraseñas generadas con cifrado XOR local. |
| 🖥️ **Monitor de Procesos** | Lista procesos activos en RAM con fines forenses. |
| ☁️ **Historial Cloud** | Sincroniza y visualiza todas las auditorías realizadas en Supabase. |

## 🛠️ Tecnologías Utilizadas

| Tecnología | Uso |
|------------|-----|
| **Python 3.10+** | Lenguaje principal. |
| **CustomTkinter** | Interfaz gráfica moderna y personalizable. |
| **Supabase** | Backend en la nube para almacenamiento de auditorías. |
| **Pwned Passwords API** | Verificación de contraseñas filtradas. |
| **Socket & Subprocess** | Escaneo de puertos y monitoreo de procesos. |
| **Dotenv** | Gestión segura de variables de entorno. |
